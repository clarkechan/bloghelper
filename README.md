# bloghelper

> 博客美化资源合集：收集了 WordPress / Hexo 博客装饰常用的 JS、CSS、字体、图片与小组件，可以直接通过 jsDelivr CDN 引用。

## 目录

| 目录 | 内容 |
| --- | --- |
| [`js/`](js) | 鼠标点击特效、输入框火花、页面焦点标题、下雪 / 樱花飘落、APlayer / Meting 音乐播放器等脚本 |
| [`css/`](css) | 灯笼挂饰、鼠标火焰、表情晃动等装饰样式 |
| [`mouse/`](mouse) | 鼠标指针样式与点击特效 |
| [`chatbox/`](chatbox) | 基于 BotUI 的对话式「关于我」组件 |
| [`donate/`](donate) | 打赏页面模板（`drinks` 与 `simple` 两种风格） |
| [`progress-wrapper/`](progress-wrapper) | 阅读进度条（PHP） |
| [`vanilla3D/`](vanilla3D) | vanilla-tilt 3D 倾斜效果 |
| [`fonts/`](fonts) | 中文手写 / 艺术字体（woff2） |
| [`images/`](images) · [`logo/`](logo) | 背景视频、图片与 Logo 素材 |
| [`docker/`](docker) · [`others/`](others) | Nextcloud、Netdata 等自建服务的配置备份 |

## 使用方法

所有文件都可以通过 jsDelivr 直接引用，把路径替换成仓库内的实际路径即可。

**引用脚本**

```html
<script src="https://fastly.jsdelivr.net/gh/clarkechan/bloghelper@latest/js/XXX.js"></script>
```

**引用样式**

```html
<link rel="stylesheet" href="https://fastly.jsdelivr.net/gh/clarkechan/bloghelper@latest/css/XXX.css">
```

**引用图片**

```
https://fastly.jsdelivr.net/gh/clarkechan/bloghelper@latest/images/XXX.webp
```
